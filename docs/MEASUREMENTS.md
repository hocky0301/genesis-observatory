# Measurement record

Generated by `node tools/build-report.mjs`. JSON files in `evidence/` are the primary records.

## Observation schedules

The short run uses the original default world, seed 42, 300 ticks, never / every tick. The stress fixture uses seed 1337, 1500 ticks, 120 founders, capacity 700, 1200 × 900, species threshold 0.35, mutation rate 0.30; all other settings are retained and recorded in each JSON. No fingerprint calls `metrics()`. Physical hashes cover individual IDs, positions, motion/energy/life counters, genotypes, sampled inputs and outputs, resource pools and free lists, both RNG streams, blooms, and the innovation registry. Full serialized-state purity is checked separately by metrics-test.mjs. Fingerprint v2 also includes the next individual ID; species hashes include ordered individual assignments, the next species ID, representative genomes, counts, liveness, peaks, last-seen ticks and fitness bookkeeping. The earlier v1 test records are retained under evidence/observer-v1.

## Browser rendering benchmark

Status: **complete-with-rejected-cases**. Fixed camera zoom 0.4: original WebGL, current WebGL, current WebGL with clade and synthetic ribbon. Canvas only when --fallback is supplied.

The renderer fixture contains 8,000 organisms, 16,000 food particles and 5,800 carrion particles at a fixed 1280 × 720 viewport. These are rendering measurements with no simulation worker running. Each current renderer uses the same fixture as the preserved incoming renderer. CPU submission time is not GPU execution time. The optional ribbon is a synthetic 320-column history, repainted every frame as a stress condition. Raw intervals, source hashes, power and background CPU probes are retained in evidence/render-benchmark.json.

Protocol 2: Aggregate CPU idle must be at least 75% for five seconds immediately before each case and for five seconds after rendering stops. During-case CPU and all load averages are reported, not admission gates.

The initial absolute-load protocol and its rejected samples are preserved separately. The later CPU-idle protocol was declared before its samples; it checks background idle for five seconds before and after each case, while reporting the tested renderer’s own during-case load separately. Cases that fail the background gate remain rejected even when their observed FPS exceeds the target. No unrelated user process or OS power preference was changed.

Observed FPS criterion, independently of the background gate: **true**. This result applies to the recorded runtime and fixture; it is not a full-application or mobile-device guarantee.

An empty requestAnimationFrame probe showed about 30 Hz in both headless and headed Chrome while the battery was very low. The final comparison records its own power state; the earlier battery diagnostics are not substituted for it. Power state was not recorded in the earlier Node CPU run, so its wall times should not be treated as a controlled comparison with this later browser run.

## Interpretation limits

A designed artificial ecosystem, not a model of a real habitat.

Diet colors are genetic labels, not measured energy flows.

A single-seed intervention is not a general ecological law.

Replay equality is tested on the same runtime; cross-engine equality is not guaranteed.
